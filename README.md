# ניחוחות השף — אתר הזמנות

אתר הזמנת קייטרינג בעברית (RTL) עם סרטון פתיחה, בניית הזמנה מלאה
ופאנל ניהול הזמנות.

**האתר החי:** https://chef-scent-magic.lovable.app
**ניהול הזמנות:** https://chef-scent-magic.lovable.app/admin

---

## ⭐ מקום אחד לפיתוח

כל שינוי בקוד נעשה ב-**`lovable/src/`** בלבד, ומשם נדחף ל-Lovable.

```
lovable/src/
├─ data/menu.ts              ⭐ כל התוכן: תפריט, מחירים, חבילות, פרטי קשר
├─ components/
│  ├─ HeroFilm.tsx           הפתיחה — וידאו בלופ, גלילה על ציר הזמן, טאגליין
│  ├─ OrderBuilder.tsx       טופס ההזמנה — פרטי אירוע, ניווט, סל, תמחור
│  └─ AdminPanel.tsx         פאנל הניהול
├─ routes/
│  ├─ index.tsx              /
│  └─ admin.tsx              /admin
└─ styles.css                הפלטה והגופן
```

**אל תערכו את `site/`.** הוא נשאר בריפו רק בשביל הנכסים (ראו למטה),
והאפליקציה שבתוכו היא אב־טיפוס מוקפא. ראו `site/ARCHIVED.md`.

## נכסים — למה `site/` נשאר

התמונות, הגופנים והוידאו מוגשים לאתר החי דרך jsDelivr **ישירות מהריפו הזה**:

```
https://cdn.jsdelivr.net/gh/yifat305/nichochot-hashef@main/site/...
```

זו הסיבה שהריפו ציבורי, וזו הסיבה ש-`site/img`, `site/fonts` ו-`site/video`
חייבים להישאר במקומם. **שינוי נתיב או מחיקה שם ישברו את האתר החי.**

הוספת תמונה חדשה: לשים אותה תחת `site/img/...`, לדחוף, ולהוסיף את הפריט
ל-`lovable/src/data/menu.ts` עם הנתיב `${ASSETS}/img/...`.

## פירוק סרטון לפריימים

```bash
ffmpeg -y -i "video.mp4" -an -vf "scale=1280:-2" -c:v libx264 -preset slow \
  -crf 25 -g 6 -keyint_min 6 -sc_threshold 0 -pix_fmt yuv420p \
  -movflags +faststart "site/video/name.mp4"
```

ה-keyframes הצפופים (`-g 6`) הכרחיים: בלעדיהם הדפדפן מנגן את הסרטון
אבל לא מסוגל לדלג בתוכו, והגלילה על ציר הזמן לא עובדת.

## מה שעדיין לא נעשה

**הזמנות לא נשלחות למייל אוטומטית.** הדפדפן לא יכול לשלוח מייל, ולכן
הוואטסאפ והמייל הם קיצורי דרך שדורשים לחיצה של הלקוח.

**פאנל הניהול שומר ב-localStorage**, כלומר בדפדפן שבו ההזמנה נשלחה.
בפועל הוא לא יראה הזמנות של לקוחות.

**קוד הכניסה גלוי בקוד המקור** — חסימה נוחה, לא אבטחה.

שלושת אלה נפתרים באותה עבודה: מסד נתונים (Supabase) ושליחת מייל (Resend),
שניהם מובנים ב-Lovable.
