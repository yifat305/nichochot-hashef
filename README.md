# ניחוחות השף — אתר הזמנות

אתר הזמנת קייטרינג בעברית (RTL), עם סרטון פתיחה מבוסס Image Sequence
ובניית הזמנה מלאה עם חישוב מחיר חי.

## הרצה

```bash
node site/server.js
```

ואז לפתוח http://localhost:5177

## מבנה

```
site/
├─ index.html          נקודת הכניסה
├─ style.css           כל העיצוב
├─ app.js              חוויית הסרטון — לופ, גלילה, טאגליין
├─ menu.js             ⭐ כל התפריט, המחירים והחבילות
├─ order.js            טופס ההזמנה והחישוב
├─ recipes.js          רשימת הסרטונים
├─ server.js           שרת סטטי בלי תלויות
├─ fonts/              FUP Lachish
├─ img/                תמונות המנות, הלחמים, עריכות השולחן והלוגו
└─ recipes/
   └─ pastel-basar/
      ├─ poster.webp   תמונת הפתיחה
      ├─ wide/         196 פריימים 16:9  (דסקטופ)
      └─ tall/         196 פריימים 9:16  (מובייל)
```

## איפה משנים מה

כמעט כל שינוי תוכן הוא ב-**`site/menu.js`**:

| מה | איפה |
|---|---|
| מחירי החבילות | `PROGRAMS.weekday.packages` / `PROGRAMS.shabbat.packages` |
| מנות, סלטים, קינוחים | `MENU` |
| כמה בוחרים מכל קטגוריה | `groups` — השדה `pick` |
| טלפון, וואטסאפ, מייל | `PHONE` · `WHATSAPP` · `EMAIL` |
| בקבוק לכל כמה סועדים | `GUESTS_PER_BOTTLE` · `BOTTLE_SPARE` |
| ספייר בקינוחים | `DESSERT_SPARE` |
| צבעי חד־פעמי | `COLORS` |

## שתי תוכניות

האתר מחליף תפריט ומחירון שלם לפי המועד:

- **יום חול** — 119 / 149 / 179 ₪ לסועד
- **שבת וחג** — 250 / 300 / 350 ₪ לסועד, שלוש סעודות

## מודלי תמחור

| סוג | חישוב |
|---|---|
| חבילה | מחיר לסועד × מספר סועדים |
| פריט עם `extra` בקטגוריית בחירה | תוספת לסועד |
| מנות פתיחה / קינוחים | מחיר ליחידה × כמות |
| שתייה חריפה | תוספת לסועד |

## פירוק סרטון לפריימים

ההוראות המלאות ב-[site/README.md](site/README.md). בקצרה:

```bash
ffmpeg -y -i "video.mp4" -vf "fps=12,scale=1280:-2" -c:v libwebp -q:v 74 -compression_level 5 -f image2 "site/recipes/<id>/wide/f_%04d.webp"
```

## הערה

קבצי המקור — שני הסרטונים המקוריים ותמונות ה-PNG ברזולוציה מלאה — אינם בריפו
(ראו `.gitignore`). כל מה שנגזר מהם כבר נמצא בתוך `site/`.
