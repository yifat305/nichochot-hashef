# ⚠️ אב־טיפוס מוקפא

**אל תפתחו כאן.** הקוד בתיקייה הזו הוא הגרסה הראשונה של האתר —
HTML, CSS ו-JavaScript רגיל. הוא הוביל אותנו לעיצוב ולהיגיון הנוכחיים,
אבל **אינו** מה שרץ באתר החי.

הפיתוח נעשה ב-**`lovable/src/`** בלבד. ראו את ה-README בשורש.

## למה התיקייה עדיין כאן

בגלל הנכסים. האתר החי מושך אותם מכאן דרך jsDelivr:

```
https://cdn.jsdelivr.net/gh/yifat305/nichochot-hashef@main/site/...
```

| תיקייה | מוגשת לאתר החי | לגעת? |
|---|---|---|
| `img/` | ✅ תמונות מנות, סלטים, עריכות שולחן, לוגו | להוסיף בלבד |
| `fonts/` | ✅ FUP Lachish | לא |
| `video/` | ✅ סרטון ההכנה והפוסטר | לא |
| `recipes/` | ❌ 392 הפריימים המקוריים | לא בשימוש |
| קבצי הקוד | ❌ | מוקפא |

**שינוי שם או מחיקה תחת `img/`, `fonts/` או `video/` ישברו את האתר החי.**

## הרצת האב־טיפוס

עדיין עובד, אם רוצים להשוות:

```bash
node site/server.js
```

http://localhost:5177 · הניהול ב-`/admin.html`
